# Subnet Learning V3

نسخة جديدة مستقلة من منصة تعلم IPv4 Subnetting، مع إبقاء الموقع الحالي في جذر المستودع دون تغيير.

## تشغيل محلي
افتح `index.html` في متصفح حديث. لا يلزم تثبيت حزم أو إنشاء حساب.

## النشر
بعد حفظ الملف في المسار `v3/index.html` في الفرع المنشور عبر GitHub Pages، يكون الرابط المتوقع:
https://aalrehilli.github.io/ipv4-subnetting-trainer/v3/

## محتويات النسخة الأولية
- واجهة عربية RTL متجاوبة.
- حاسبة IPv4 Subnetting.
- محول Binary/Decimal تفاعلي.
- بطاقات دروس تعليمية.
- مختبر ألعاب أولي.
- تمرين حساب عدد العناوين.
- جدول بادئات شائع.

## ملاحظات
هذه بداية V3.1 وليست بديلًا نهائيًا عن تدقيق جميع وظائف النسخة الحالية. يجب اختبار الحسابات والألعاب وتوسيعها قبل اعتبارها إصدارًا نهائيًا. لا توجد حسابات للمتعلمين في هذه النسخة.

📚 المسار التعليمي

ابدأ من أنظمة العد ثم انتقل إلى تقسيم الشبكات خطوة بخطوة.

الوحدة 01

أنظمة العد

Binary وDecimal وقيم البتات والتحويل بين النظامين.

الوحدة 02

أساسيات IPv4

الأوكتتات وعناوين IP والفرق بين الشبكة والمضيف.

الوحدة 03

Subnet Mask وCIDR

فهم القناع والبادئة وبتات الشبكة والمضيف.

الوحدة 04

مبادئ Subnetting

استعارة البتات وحساب الشبكات والمضيفين.

الوحدة 05

Magic Number

حساب Block Size وتحديد نطاق كل شبكة فرعية.

الوحدة 06

Network وBroadcast

إيجاد أول وآخر مضيف وعنوان البث.

الوحدة 07

FLSM

تقسيم شبكة إلى شبكات متساوية الحجم.

الوحدة 08

VLSM

توزيع الشبكات حسب احتياجات المضيفين المختلفة.

الوحدة 09–10

المختبر والمراجعة

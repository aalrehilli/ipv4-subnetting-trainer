# IPv4 Academy V2

نسخة جديدة مستقلة مبنية على خبرة منصة IPv4 Subnetting Trainer الحالية.

## الهدف
منصة تدريبية واضحة تعتمد دورة:
**تعلّم → تدرّب → اختبر → حلّل → حسّن**

## مبادئ V2
- واجهة عربية RTL واضحة.
- فصل الطالب عن المدرب.
- Student 360 بدل تقارير متفرقة.
- Trainer Command Center بدل لوحات كثيرة متداخلة.
- التحليلات الثقيلة تكون في PostgreSQL/RPC وليس في المتصفح.
- كل ميزة جديدة تكون داخل Module مستقل.
- الأمان يعتمد على RLS والصلاحيات في قاعدة البيانات.

## المسار الأول
IPv4 → Binary → Prefix → Subnet Mask → FLSM → VLSM → Assessment.

## المسار المستقبلي
Routing → Switching → VLAN → IOS → Network Security → CCNA.
